## 1. Executive Summary

Nuvra v1 Core on branch `release/v1` integrates the borderless DirectComposition glassmorphic notch host, 4-state spring animator (including `Banner` toast popups), multi-session WinRT GSMTC media/video controller with clickable seek and live WASAPI loopback 32-band FFT spectrum visualizer, global mic mute + call/camera live sensors, Focus Assist (`SHQueryUserNotificationState`) + `UserNotificationListener` bridge, drag-in/drag-out File Shelf with Explorer reveal & non-overwriting ZIP compression, exclusion-protected Clipboard Vault with pinning, Fluent `en-US` catalog, Windows theme/high-contrast sync, and startup registration.
